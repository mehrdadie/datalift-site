# Agent Task — Hero Motion & Interaction

Work only on branch `agent/hero-motion`.

## Objective
Create a premium, simple, highly polished Datalift hero with tasteful motion/video-like ambience that works beautifully on desktop and mobile.

## Direction
- Keep the hero simple and outcome-led; avoid graphs, dashboards, or generic analytics charts as the main visual.
- Use elegant motion, layered depth, subtle animated texture, light, typography, or abstract data-flow-inspired movement.
- The result should feel modern, premium, trustworthy, and appropriate for small and mid-size non-technical businesses.
- Animation must support the message rather than distract from it.
- Preserve fast loading and smooth performance.
- Build a graceful reduced-motion fallback.
- Make the mobile hero intentional rather than a compressed desktop version.
- CTA buttons must route correctly.

## Do Not Touch
- Header/navbar/dropdowns.
- Body-section copy outside the hero unless absolutely necessary.
- Footer.

## QA
Test 1440, 1024, 768, 390, and 360px widths. Check CLS, overflow, motion smoothness, reduced-motion behavior, CTA functionality, and build/lint/typecheck.
